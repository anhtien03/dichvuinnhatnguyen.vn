# Quy tắc làm việc dự án innhatnguyen.vn

## 1. Kiểm soát Git & Triển khai (BẮT BUỘC TUÂN THỦ)
- **TUYỆT ĐỐI KHÔNG tự ý chạy lệnh `git push`**: Mọi thao tác push code lên GitHub/remote repository sẽ do người dùng tự thực hiện thủ công.
- Sau khi chỉnh sửa code hoặc build xong (`npm run build`), chỉ báo cáo các file đã thay đổi để người dùng tự review và push code.
